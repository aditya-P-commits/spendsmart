SpendSmart is a student-friendly web application designed to record and review daily pocket expenses.

Key Features & Implementation Details:
- HTML5 & CSS3 with Bootstrap 5.3
- Clean, realistic student project UI:
  - Welcome Landing Page (index.html)
  - Home Dashboard (dashboard.html) with key status indicators and quick-log access
  - Note Down Expense Form (add-expense.html) with category and payment mode selection
  - Expenses Record Table (view-expenses.html) with clean category filters
  - Project & Team Details (about.html)
- Responsive, pure CSS flex navigation bar for mobile, tablet, and desktop viewports.
- Flat design style without modern startup clutter.
